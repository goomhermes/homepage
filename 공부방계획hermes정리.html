1. 한국 공부방 개요

공부방은 학원과 과외의 중간 형태로, 선생님 자택에서 소규모(10명 이내) 학생을 대상으로 운영됩니다. 학습 지도와 '돌봄' 기능을 겸하며, 맞벌이 부부에게 인기가 높습니다.

주요 특징

항목설명
소규모 그룹개별 피드백 · 질의응답이 활발하며, 학생 성향·수준 파악 용이
가정적 분위기편안한 환경, 간식 제공 등으로 어린 학생 적응 용이
종합적 관리국어·영어·수학 등 주요 과목 또는 전문 과목 + 생활 지도
반복·선행 학습학교 진도 복습 + 다음 학기/학년 과정 선행 학습

일반적 수업 방식

  • 자기주도학습 + 코칭: 학생이 문제집을 풀고, 모르는 부분을 1:1로 질문
  • 개념 설명 + 문제 풀이: 선생님이 15~20분 핵심 개념 설명 후 관련 문제 풀이
  • 정기 평가: 매일 단어 시험, 주간 테스트, 월말 평가 → 학부모 공유

2. 연령별 학습 목표 · 커리큘럼 · 수업 구성

1~2학년 저학년 영어

핵심: '학습'이 아닌 언어 습득(Acquisition) — 재미와 자신감 형성이 최우선. '에듀케어(Edu-Care)' 성격.

항목내용
운영주 2~3회, 회당 40~60분
커리큘럼 축파닉스 + 노래 + 스토리 + 게임 (주제 중심 통합 학습)
파닉스 진행알파벳 음가 → 단모음 → 장모음 → 이중자음/이중모음 (1년+ 장기)

학습 목표

  • 알파벳 대소문자 인지 및 파닉스 기초
  • 기초 필수 어휘 100~200개 (색깔, 숫자, 동물, 가족, 음식 등)
  • 영어에 대한 친밀감·자신감 형성
  • TPR을 통한 듣기 능력 기초

  • 5~8문장 문단 읽기 및 주제 파악

3. 파닉스 수업 시나리오 (저학년)

파닉스 학습 단계

단계내용예시
1단계알파벳 인지 (이름, 모양, 음가)A [æ], B [b], C [k]
2단계단모음 + CVC 단어c-a-t, p-e-n, p-i-g
3단계장모음 + Magic 'e'cap → cape
4단계이중 자음·모음 (Blends, Digraphs, Diphthongs)sh, ch, th, ee, oa

50분 수업 시나리오 — Short 'a' [æ]

목표: cat, hat, mat 단어를 읽고 쓸 수 있다.

시간활동선생님 행동·SCRIPT효과
0~5분Warm-upHello Song + Alphabet Chant로 전체 음가 복습영어 모드 전환, 활기 조성
5~15분소리 소개"'a' makes the [æ] sound!" — 입 모양·제스처 과장
"ants eating apple! [æ] [æ] ant!"		시각·청각·신체 다중 감각 각인
15~30분블렌딩1) 소리 분절: /k/ /æ/ /t/
2) 소리 조합: "/k-æ-t/" → "Cat! Magic!"
3) 단어 가족: cat, hat, mat (-at family)		조합 읽기 개념 + 라임 어휘 확장
30~45분게임Flyswatter Game: 단어 듣고 파리채로 치기
+ 간단한 워크시트		경쟁 몰입, 소근육·철자 인지
45~50분마무리"You can read cat, hat, mat! Great job!" + 스티커
Goodbye Song		성취감, 다음 수업 기대감
